# [SWEA] 20230. 풍선팡 보너스게임 2

## 문제
N×N 격자의 각 칸에 풍선이 들어 있는 보너스 게임에서, 한 칸을 선택했을 때 얻을 수 있는 점수의 최댓값을 구한다.
코드 기준으로 선택한 칸의 가로줄과 세로줄(십자 방향) 전체 합을 점수로 계산하며, 모든 칸 중 최댓값을 테스트케이스별로 출력한다.

## 풀이
### 알고리즘
완전탐색 (모든 칸을 기준으로 십자 방향 합 계산)

### 풀이 방법
1. 테스트케이스마다 N과 N×N 배열을 입력받는다.
2. 모든 칸 (i, j)를 선택 후보로 순회한다.
3. i행 전체 합 `sum(arr[i])`에 j열 전체 합을 더한다.
4. (i, j) 칸이 행과 열에서 두 번 더해졌으므로 한 번 뺀다.
5. 지금까지의 최댓값과 비교해 갱신하고, 마지막에 `#tc 최댓값`을 출력한다.

### 복잡도
- 시간복잡도: O(N³) (칸 N² × 열 합 계산 N)
- 공간복잡도: O(N²)

### 핵심 포인트
- 십자 합 = 행 합 + 열 합 - 중복된 교차 칸 하나.
- 행/열 누적합을 미리 구해두면 O(N²)으로 줄일 수 있다.

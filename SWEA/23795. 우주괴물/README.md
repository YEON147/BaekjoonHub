# [SWEA] 23795. 우주괴물

## 문제
N×N 격자에 빈 칸(0), 장애물(1), 우주괴물(2)이 있다. 우주괴물은 상하좌우 네 방향으로 장애물이나 격자 끝을 만날 때까지 공격한다. 공격받지 않는 안전한 칸(0)의 개수를 구한다.

## 풀이
### 알고리즘
구현 / 시뮬레이션 (4방향 직선 탐색)

### 풀이 방법
1. 격자를 입력받고 값이 2인 우주괴물의 좌표를 찾는다.
2. 상하좌우 각 방향으로 한 칸씩 전진하며 공격 범위를 표시한다.
3. 격자 밖이거나 장애물(1)을 만나면 해당 방향 탐색을 중단한다.
4. 공격받은 칸은 1로 바꿔 표시한다.
5. 마지막에 남은 0의 개수를 세어 출력한다.

### 복잡도
- 시간복잡도: O(N²)
- 공간복잡도: O(N²)

### 핵심 포인트
- 방향 벡터 배열과 배수(n)를 이용해 4방향 탐색을 간단히 구현한다.
- 장애물을 만나면 그 방향은 즉시 break 해야 뒤쪽 칸이 보호된다.
